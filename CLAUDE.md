# voxd

Headless voice-to-text daemon for Wayland/sway. Transcribes via OpenRouter's `/audio/transcriptions` endpoint and injects the result with `wtype`. Controlled by SIGUSR2 (toggle start/stop) — no GUI, no overlay, no tray.

## Status

Pre-implementation. See [docs/plan-voxd.md](docs/plan-voxd.md) for the design, decisions log, and the 12-step TDD roadmap.

## Overview

```
SIGUSR2 → daemon → sounddevice capture → Silero VAD (trim silences)
       → POST /audio/transcriptions @ OpenRouter
       → wtype <text>   (FIFO-serialized so concurrent recordings keep order)
```

The pipeline (audio capture params, VAD smoothing constants, OpenRouter wire format, retry policy) is a direct port of the Rust code in the `handy` repo, branch `feat/openrouter-transcription` — see `src-tauri/src/audio_toolkit/` and `src-tauri/src/llm_client/` there for the reference implementation. Re-deriving these choices is wasted work.

## Distribution

Installed via `uv tool install voxd`. The daemon runs as a `systemd --user` service generated by `voxd setup`, which also writes `~/.config/sway/config.d/voxd.conf` with a `Ctrl+Alt+Space` toggle bindsym.

## Sub-commands

- `voxd` — daemon foreground (default)
- `voxd toggle` — send SIGUSR2 (used by sway bindsym)
- `voxd setup` — interactive: prompts for API key, writes config TOML + systemd unit + sway snippet
- `voxd config [--edit]` — show or edit `$XDG_CONFIG_HOME/voxd/config.toml`
- `voxd doctor` — check `wtype`, `notify-send`, PortAudio, mic access

## Tech stack

- Python ≥ 3.11 (tomllib stdlib)
- `uv` (deps, `uv tool install`), `ruff`, `ty`, `pytest`
- `sounddevice` (PortAudio) — capture
- `onnxruntime` — Silero VAD
- `scipy` — resampling
- `httpx` — async HTTP client
- System deps: `wtype`, `notify-send` (libnotify), PortAudio shared lib
